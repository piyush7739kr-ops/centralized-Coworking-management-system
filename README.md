# 🏢 NexSpace - Coworking Space Management System

A responsive, single-page web platform designed to streamline coworking space reservations, workspace inventory, and administrative management. Built as a coursework practical project for Internet Programming (CSC 326).

🔗 **[Launch NexSpace Web Application](https://piyush7739kr-ops.github.io/Co-working-management/)**

---

## 📌 Key Features

### 👤 Member / Client Features:
- **Workspace Catalog:** Browse diverse space types (Hot Desks, Dedicated Desks, Private Cabins, and Conference Rooms).
- **Search & Dynamic Filters:** Instant filtering by space category and keyword search.
- **Reservation Workflow:** Interactive booking modal with date pickers, slot durations, and automated total cost estimation.
- **Booking Status Tracking:** Real-time visibility into booking statuses (`Pending`, `Confirmed`, `Cancelled`).
- **User Authentication:** Client sign-in and account registration.

### 🛠️ Admin / Hub Manager Features:
- **Secure Password-Protected Portal:** Dedicated login route for workspace administrators.
- **Full Inventory CRUD:** Create, Read, Update, and Delete coworking spaces dynamically.
- **Booking Approvals:** Approve or reject client booking requests with instant status reflections.
- **Real-Time Analytics:** Workspace utilization rates, total bookings counter, and revenue summaries.
- **Password Management:** Update admin credentials directly from the settings drawer.

## 💻 Tech Stack (Curriculum Mapped)
- **Structure:** Semantic HTML5 (`header`, `nav`, `section`, `article`, `dialog`)
- **Styling:** Tailwind CSS (Modern utility-first responsive layout, Flexbox & CSS Grid)
- **Logic & Interactivity:** Vanilla JavaScript (ES6+ DOM manipulation, Event Handling, Higher-Order Array Methods)
- **Data Persistence:** Browser `Web Storage API (LocalStorage)` for persistent state across sessions
- **Hosting & Deployment:** GitHub Pages
